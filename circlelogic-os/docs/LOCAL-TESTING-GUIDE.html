Update the installation you already use

Close the application's terminal window. Extract the update ZIP and run APPLY-UPDATE.cmd. Choose your existing circlelogic-os folder. The updater checks file versions and backs up changed code. It leaves your database, login, MFA, .env and vault key alone.

Restart START-CIRCLELOGIC.cmd in the existing folder, then press Ctrl+F5 in the browser. Check that the footer says v06.

First connection: setup once

Open API Connections → Diary / Calendar → Add API → Setup guide. In One-time connection setup, save the Application client ID and Directory (tenant) ID from the approved Microsoft app registration. Register the exact Web redirect URI shown in the guide in Microsoft. Select Save setup and paste key.

These IDs are necessary because Microsoft does not authenticate this connection using a standalone API key. The form stays simple because the IDs are remembered separately. REA similarly needs its Partner client ID and authorised agency ID saved once in its guide.

Paste, save, authorise

Paste only the Microsoft client secret Value into the key field, select Save key, and select Authorise Microsoft. Finish consent, return and select Test and sync. For REA, paste the Partner client secret, save and select Sync now.

testing123 is your CircleLogic test login, not a Microsoft client ID or API key. A normal mailbox password, the Microsoft Secret ID and a temporary access token are also not substitutes for the client secret Value. Use a private CircleLogic account and an approved test mailbox for real connection tests.

Already connected in v05?

Your saved IDs are reused. Choose Manage → Replace key and paste the new secret. No need to type those IDs again. Editing IDs in the guide takes effect only when you save a corresponding key. Existing secrets are never displayed back.

What has not changed

Two-factor authentication and workspace restrictions remain in place. Saving a key does not label a connection live before authorisation and a successful import. Agentbox, Australian RP Data and Proping are still unfinished and cannot import data simply by receiving a key.

The update is not a public deployment, an independent security certification or a real provider-account test. All supplied test data is synthetic.

Official authentication references: Microsoft and REA. See TEST-REPORT.md for current evidence and START-HERE.md for launch instructions.
